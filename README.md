# Portfolio

My personal site, in English and Brazilian Portuguese: the projects I've built, how I build them, and how to reach me.

**Visit:** https://cubing-way.github.io/Portfolio/

## Pages

- **Home:** what I build, featured projects and what I'm building now
- **Projects:** a write-up of each project (the idea, features, development and current status), chosen from a menu. Link straight to one with its id, e.g. `projects.html#cubisz` (`pro-timer`, `cubisz`, `easy-score`, `mixed-units-calculator`, `fifteen-puzzle`).
- **About:** who I am, how I build, and my skills
- **Contact:** email and GitHub

The root `index.html` sends visitors to `pt-br/` when their browser's language is Brazilian Portuguese, and to `en-us/` otherwise.

## Run it

Plain HTML, CSS and JavaScript: open `index.html` in a browser. There is nothing to install or build.

## Folder layout

- `index.html`: picks the language
- `en-us/`, `pt-br/`: the same four pages, stylesheet and script, one folder per language
- `*.jpg`: project screenshots
- `Screenshots.xcf`: the GIMP file the screenshots come from
- `Currículo Caio Almeida Martins.pdf`: my CV (not linked from the pages yet)
