Pro Timer

O Pro Timer é um cronômetro para speedcubing criado para possibilitar treinos no estilo de competição sem exigir uma configuração extensa ou gerenciamento manual.

A Ideia Principal

A principal ideia do design surgiu de uma implementação acidental. Durante o desenvolvimento do cronômetro, inicialmente implementei as médias de 5 de forma incorreta, calculando-as em blocos fixos em vez de usar a média móvel dos últimos cinco tempos.

Percebi que esse comportamento poderia criar uma experiência interessante de treino semelhante a uma competição, e ele acabou se tornando a base do sistema de médias do Pro Timer.

Funcionalidades

  • Gerenciamento de sessões e resoluções
  • Estatísticas detalhadas de resoluções e médias
  • Scrambles e subsets
  • Médias em blocos sem sobreposição
  • Funcionalidades para resolução vendada
  • Funcionalidades para Fewest Moves Challenge
  • Calculadoras de TPS
  • Estatísticas diárias e gerais

Desenvolvimento

Um dos maiores desafios foi o gerenciamento de estado. Com sessões, resoluções, estatísticas, configurações, comportamentos específicos de cada evento e outros recursos interligados, manter o estado da aplicação consistente se tornou uma das partes mais difíceis do projeto.

Estado Atual

O Pro Timer é meu projeto mais desenvolvido e refinado até o momento. Ele é totalmente utilizável e a maior parte das funcionalidades planejadas já foi implementada, embora o projeto ainda não esteja completamente finalizado.

Cubisz

Cubisz é uma biblioteca de simulação e visualização do Cubo Mágico, criada originalmente para fornecer uma visualização melhor de scrambles para o Pro Timer.

A Ideia

O objetivo inicial era criar uma forma confiável de exibir scrambles. Durante o desenvolvimento, o projeto evoluiu para algo mais amplo: um Cubo Mágico digital que pode ser representado, manipulado e analisado por outras aplicações.

Atualmente, o Cubisz é utilizado pelo Pro Timer para visualização de scrambles, contagem de movimentos e verificação de soluções, cálculo de TPS e funcionalidades de FMC.

Funcionalidades Atuais

  • Simulação e visualização de cubos 2×2
  • Simulação e visualização de cubos 3×3
  • Planificação 2D do cubo
  • Visualização 3D do cubo
  • Movimentação do cubo e gerenciamento do estado das peças
  • Contagem de movimentos e verificação de soluções
  • Suporte para cálculo de TPS
  • Funções reutilizáveis para outros projetos

Desenvolvimento

Uma das partes mais difíceis foi fazer corretamente a troca das peças causada pelos movimentos do cubo, preservando ao mesmo tempo o estado real do cubo.

Estado Atual

Atualmente, o Cubisz suporta cubos 2×2 e 3×3 e pode exibi-los como uma planificação 2D ou como uma representação 3D.

A geração de embaralhamentos ainda não foi implementada, mas a base de simulação e visualização já está disponível para futuras aplicações.

Easy Score

Easy Score é um editor de partituras desenvolvido em torno de uma ideia simples: criar notação musical não deveria exigir que o usuário primeiro aprendesse a utilizar uma aplicação musical complexa.

A Ideia

Eu queria escrever partituras, mas achei as aplicações existentes de notação musical difíceis de aprender. Queria criar algo em que conhecimentos básicos de música e uma interface intuitiva fossem suficientes para começar a transformar ideias em partituras.

Em vez de seguir fortemente as convenções dos programas de notação existentes, busquei ideias de interação em aplicações como editores de texto, vídeo e imagem, utilizando conceitos que os usuários já conhecem.

Funcionalidades Atuais

  • Gerenciamento de pautas
  • Criação e gerenciamento de compassos
  • Gerenciamento de claves, fórmulas de compasso e armaduras de clave
  • Entrada de notas por texto
  • Salvamento e gerenciamento do estado da aplicação
  • Reprodução das partituras geradas
  • Entrada de notas pelo mouse em desenvolvimento

Desenvolvimento

Easy Score é meu projeto mais complexo até agora. Gerenciar a inicialização da aplicação e restaurar seu estado foi um dos maiores desafios técnicos.

A entrada de notas pelo mouse é outro desafio em andamento, já que a posição e a interação do usuário precisam ser traduzidas para a notação musical correta.

Estado Atual

Atualmente, o Easy Score permite escrever partituras básicas utilizando entrada de notas por texto. É possível criar as pautas necessárias, escrever músicas nelas e reproduzir a partitura resultante.

O projeto ainda está em desenvolvimento. Nem todos os símbolos de uma partitura são suportados e a entrada de notas pelo mouse ainda está sendo desenvolvida.

Calculadora de Unidades Mistas

A Calculadora de Unidades Mistas foi criada para tornar cálculos envolvendo várias unidades mais intuitivos.

A Ideia

A ideia surgiu durante uma competição de Cubo Mágico. Havia um limite de tempo acumulado de dez minutos, e eu precisava subtrair os tempos das resoluções já realizadas desse limite, trabalhando com minutos, segundos e milissegundos ao mesmo tempo.

Isso me fez perceber que cálculos com unidades mistas podem ser desnecessariamente difíceis quando uma calculadora exige que tudo seja convertido primeiro para uma única unidade.

O Conceito

O objetivo é permitir que o usuário insira e receba valores nas unidades que fazem sentido para ele, enquanto a aplicação cuida das conversões internamente.

Funcionalidades Atuais

  • Entrada de unidades mistas
  • Saída em unidades mistas
  • Cálculos com horas, minutos e segundos juntos
  • Conversão automática entre unidades

Estado Atual

O projeto ainda está em uma fase inicial de prova de conceito. O protótipo atual demonstra a ideia principal permitindo inserir e calcular horas, minutos e segundos juntos.

GitHub: Calculadora de Unidades Mistas no GitHub

15-Puzzle Simulator

O 15-Puzzle Simulator é um simulador moderno de quebra-cabeças deslizantes, criado para tornar a prática e exploração de puzzles maiores mais agradável.

A Ideia

Recebi um 15-puzzle como presente por participar de uma competição. Depois de experimentar o puzzle, fiquei interessado em resolvê-lo e até desenvolvi meu próprio método para isso.

Eu queria experimentar puzzles deslizantes maiores, então procurei simuladores online. As opções disponíveis não ofereciam a combinação de design visual, layout moderno, embaralhamento e funcionalidades gerais que eu procurava.

Funcionalidades Atuais

  • Simulação de puzzles de 3×3 até 10×10
  • Temas visuais personalizáveis
  • Interface e layout modernos
  • Embaralhamento do puzzle
  • Contador de movimentos
  • Cronômetro
  • Opções de personalização

Desenvolvimento

Um dos principais desafios técnicos foi mover e trocar as peças do puzzle sem quebrar a estrutura do DOM.

O projeto também exigiu um gerenciamento cuidadoso do layout para que diferentes tamanhos de puzzle continuassem utilizáveis dentro da interface.

No Que Me Concentrei

As partes das quais mais me orgulho são o estilo visual e o sistema de embaralhamento. Eu queria que o simulador tivesse a aparência de uma aplicação moderna, em vez de simplesmente exibir uma grade de peças na página.

Estado Atual

O simulador está próximo de ser finalizado e pretende ser minha primeira aplicação disponibilizada publicamente fora dos projetos hospedados pelo GitHub Pages.

No futuro, quero integrar o Cubisz e expandir o projeto para transformá-lo em um simulador de puzzles mais completo.
